# Week 9 Practice Problems

Five standalone Java solutions for the Week 9 object-oriented programming
practice problems. Each solution is in its own folder and can be compiled
and run independently.

## Problems

1. `Problem1_GardenPlotAreaReport` - calculates each garden plot's area and the total.
2. `Problem2_WeeklyStaffPay` - calculates weekly pay for full-time staff, hourly staff, and interns.
3. `Problem3_LibraryLateFineCounter` - calculates late fines for books, DVDs, and magazines.
4. `Problem4_ElectricityConnectionBilling` - calculates bills for homes, shops, and factories.
5. `Problem5_TravelBookingWithCommonFee` - calculates bus, train, and flight fares with a shared booking fee.

The solutions require Java 8 or newer. Each uses standard input and prints
monetary values or areas to two decimal places.

## Compile and run

From the project root, compile and run a solution by replacing the folder
name below with the problem you want to run:

```text
javac Problem1_GardenPlotAreaReport\Main.java
java -cp Problem1_GardenPlotAreaReport Main
```

Enter the input described in the corresponding problem statement. For example,
the garden area report accepts:

```text
3
CIRCLE Asha 5
RECTANGLE Ravi 4 6
TRIANGLE Neha 10 3
```
